### 正文（Markdown）

```markdown
## 许愿助手是什么

给团长和团员用的**许愿 + 拍卖**插件，适用于《魔兽世界》「无限」。团员在团队频道发一句话就能许愿，团长这边自动录入、全团同步，掉了装备直接开拍，出分、倒数、Roll、扣分全部自动完成。

## 主要功能

**许愿**
- 团队频道发 `xy` + 装备链接即可许愿，也可以 `xy [装备名]`，或直接写简称 `xy 墓碑`（简称由团长人工处理）
- 团长代许愿：`txy 名 姓 装备`
- "地板"许愿：`xy 地板`，愿意要没人要的东西
- 每人许愿件数上限、同一件多人许愿时提醒
- 团队频道有人贴装备时，自动报出谁许愿了这件

**分数**
- 默认分数、加减分、全团初始化
- 许愿加分 +5：拍自己许愿的装备时，最多可出"现有分数 + 5"
- 许愿列表一眼看出谁还有许愿、谁有 +5

**掉落与扣分**
- 自动记录掉落
- 装备分给拍卖赢家时自动按出分扣分
- 拿到许愿的装备自动标记完成

**拍卖**
- 团队频道出现的装备自动进"待拍"，点一下就开拍
- 弹窗出分按钮：1~4 分，许愿的人另有 6~9 分
- 许愿者开拍 1 秒后自动出 5 分
- 倒数三二一、同分自动进 Roll、直接全团 Roll、"不要这件"
- 许愿截止后才能开拍，避免看到掉落再许愿

**真人语音播报**
- 开拍、出分、倒数、被超过、拍到、拍完都有语音提示
- 配音：喵啾啾；不想要可以在设置里关掉

**数据安全**
- 团长掉线、游戏崩溃后，从团员手里找回最新的许愿表
- 自动快照
- 导出备份码（防手改），随时导入恢复

**界面**
- 扁平暗色 / 暴雪原生两种风格，随时切换
- 右键团员菜单、小地图按钮、按键绑定

## 怎么用

1. 团长：`/xy` 打开窗口，点"开始许愿"，团队频道会发开团公告
2. 团员：团队频道发 `xy` + 装备链接
3. 掉了装备：点屏幕上的"待拍"选一件开拍（会先截止许愿）
4. 团员在弹窗里点分数出分，倒数结束自动结算
5. 把装备分给赢家，插件自动扣分

常用命令：`/xy` 打开窗口　`/xy help` 全部命令　`/xypm` 拍第一件待拍装备

## 常见问题

- **为什么没自动扣分？** 装备要真正分给赢家（出现"某某获得了物品"）才会扣；交易给的不会扣。另外"设置 → 许愿规则 → 自动扣分"要开着，许愿团长要在线。
- **为什么没自动出 5 分？** 只有许愿了这件装备的人才会；写简称的许愿由团长人工处理，不会自动出分。
- **怎么关掉语音？** 设置 → 拍卖 → 取消"语音播报"，或只关"使用语音包"改用合成语音。
```
