# 开发工具：离线测试与静态检查 要求写明本机如何运行这两个工具。

## 离线测试

测试只覆盖纯逻辑模块，用普通的 Lua 5.1 运行，不需要游戏客户端。

在 `addon/RaidWish` 目录下：

```bash
lua5.1 tests/run.lua
```

全部通过时退出码为 0，否则为 1，并逐条打印失败的断言。

**本机没有 Lua 5.1 时**（当前这台电脑就是这样），用项目里的替代脚本 [tools/lua51.py](../tools/lua51.py)。它借用 Python 包 `lupa` 里内置的 Lua 5.1，需要先装好 `uv`：

```bash
uv run --no-project --with lupa python -I ../../tools/lua51.py tests/run.lua
```

（在 `addon/RaidWish` 目录下执行。首次运行时 `uv` 会自动下载 `lupa`。）

### 加测试

1. 在 `tests/` 下新建 `test_xxx.lua`，文件开头 `local T = ...`。
2. 用 `T.load({ "Core/Util.lua", ... })` 加载要测的模块，返回一个新的假 `ns`。第二个参数可以注入测试需要的游戏全局，例如 `{ RAID_CLASS_COLORS = {...} }`。
3. 断言用 `T.eq(实际, 期望, 说明)`、`T.ok(条件, 说明)`、`T.same(表, 表, 说明)`。
4. 把文件名加进 `tests/run.lua` 的 `SUITES` 列表。

## 静态检查（luacheck）

配置文件：插件用 [addon/RaidWish/.luacheckrc](../addon/RaidWish/.luacheckrc)，探测插件用 [tools/RaidWishProbe/.luacheckrc](../tools/RaidWishProbe/.luacheckrc)。可写的全局只列了 允许的那些。新用到游戏接口时，把它加进 `read_globals`。

在对应目录下：

```bash
luacheck .
```

要求零告警。

**本机**：已安装在 `D:\software\luacheck\luacheck.exe`（0.23.0）。这个目录不在 `PATH` 里，要用完整路径运行：

```bash
/d/software/luacheck/luacheck.exe .
```

**在别的电脑上安装**：Windows 上最简单的办法是从 luacheck 的 GitHub 发布页（lunarmodules/luacheck）下载单文件的 `luacheck.exe`，放进 `PATH` 里的任一目录。另一个办法是装好 Lua 5.1 和 LuaRocks 之后执行 `luarocks install luacheck`。

## 多客户端模拟（tools/sim）

[tools/sim/wow.lua](../tools/sim/wow.lua) 在本机模拟几个客户端同在一个团里，各自加载完整的 TOC。团队聊天、插件消息、拾取消息、Roll 点会在客户端之间投递。[tools/sim/run.lua](../tools/sim/run.lua) 用它把各阶段"游戏内验收"的流程跑一遍：许愿、同步、主界面、掉落、拍卖、右键菜单、两段名字、小地图按钮、皮肤切换、数据恢复。

在项目根目录：

```bash
uv run --no-project --with lupa python -I tools/lua51.py tools/sim/run.lua
```

全部通过时退出码为 0。

另外两个脚本：

```bash
uv run --no-project --with lupa python -I tools/lua51.py tools/sim/crash.lua
uv run --no-project --with lupa python -I tools/lua51.py tools/sim/perf.lua
```

- `crash.lua`：游戏崩溃后用旧存档重登（许愿团长、团员各种情况），检查数据不会丢、旧数据不会覆盖全团。
- `perf.lua`：40 人团下各操作的耗时，以及空闲、拍卖进行中每秒的耗时。数字是本机解释器里的，只用来比较改动前后和找热点。

**它能发现的问题**：运行时报错，调用了不存在的界面方法（模拟构件只认真实客户端的方法名，写错就报错），以及各端数据不一致、通报文案不对、流程走不通。

**它不能代替进游戏**：
- 不模拟真实的排版、字体和贴图，看不出界面长得对不对。
- 不模拟服务器的限流和首领战锁定。
- 游戏接口的行为是按正式服的常见情况写的；"无限"客户端的实际情况见 [探测结果.md](探测结果.md)。
