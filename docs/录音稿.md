# 许愿助手 · 语音录音稿

感谢帮忙配音！这些语音会在《魔兽世界》插件"许愿助手"里，团队拍卖装备时播放给玩家听。一共 **18 句**，都是短句，十分钟左右就能录完。

## 录音要求

- **环境**：安静的房间，关掉风扇、空调、音乐。手机或耳麦都可以。
- **距离**：嘴离麦克风大约一拳远，别贴太近（会有喷麦声）。
- **语气**：像在团里语音频道提醒队友那样，**清楚、有精神、带点情绪**。恭喜类可以开心一点，提醒类利落一点。
- **语速**：正常偏快，每句尽量在 **2 秒以内**。
- **前后留白**：每句开口前、说完后各停半秒再按停止（多出来的空白会自动剪掉）。
- **多录几遍**：每句可以录 2～3 遍，挑最好的一遍交付；拿不准就都发过来。
- **台词可以改**：括号里的"备选"随便挑，也可以按自己的说话习惯改，**意思对就行**。改过的请在交付时注明。

## 交付

- **一句一个文件**，文件名用上表的"文件名"一列，例如 `won_bid.m4a`、`bid_9.mp3`。
  - 格式随意：手机录音的 m4a、mp3、wav 都可以，不用转换。
  - 同一句录了几遍，就加编号：`won_bid_1.m4a`、`won_bid_2.m4a`。
- 打包成一个压缩包，或直接在聊天软件里一起发过来。
- 改了台词的，附一句说明就行，例如"第 9 句改成：出不了哦"。
