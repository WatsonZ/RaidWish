# 游戏内测试清单

按一次测试的先后顺序排列的游戏内检查项。

## 准备

1. 把 `tools/RaidWishProbe` 和 `addon/RaidWish` 两个文件夹复制到客户端的 `Interface/AddOns/` 下。两个账号都要装。
2. 登录界面的插件列表里确认两个插件都已勾选，且没有标"不兼容"（Interface 号为 16001）。
3. 进游戏后执行 `/console scriptErrors 1`，全程开着。**看到任何报错，把原文发给开发者。**
4. 两个角色组队，**并把队伍转成团队**（插件只在团队里通讯）。下面 A 是团长，B 是普通团员。

## 一、探测

- [ ] A：`/rwprobe info`、`/rwprobe api`、`/rwprobe tpl`，都有输出、不报错。
- [ ] 两人都执行 `/rwprobe chat on` 和 `/rwprobe menu`，然后互相在团队频道说话、贴物品链接、`/roll`，右键对方看菜单底部出现的"RaidWishProbe: 标签名"。
- [ ] A：`/rwprobe flood 60`。
- [ ] 有机会进团本时：开打首领后让 B 在团队频道说话，A 执行 `/rwprobe send`；击杀后开尸体，`/rwprobe loot`；拾取一件装备。
- [ ] 退出游戏，把 `WTF/Account/<账号>/SavedVariables/RaidWishProbe.lua` 发给开发者（两个账号的都要）。

## 二、加载与通讯

- [ ] 插件列表里有"RaidWish 许愿助手"，登录不报错。
- [ ] `/xy` 打开主窗口；`/xy help` 列出命令；`/reload` 后存档文件 `RaidWish.lua` 里有 `RaidWishDB`。
- [ ] A：`/xy debug ping` → B 显示"收到 HELLO 来自 A"。
- [ ] A：`/xy debug flood 60` → B 最终显示"60 / 60 条……全部到达且顺序正确"。
- [ ] A：`/xy debug big` → B 显示"分片重组正确"。
- [ ] 两人各执行 `/xy debug comm`，把数字发给开发者。

## 三、许愿

- [ ] A 在主窗口点"开始许愿"：团队频道出现开团公告，两人的状态行都变为绿色"许愿进行中 · 许愿团长 A"。
- [ ] B 在团队频道发 `xy` 加物品链接：A 的列表里该行闪一下；B 聊天框出现"你的许愿已记录"；B 的工具栏显示"你的许愿 [物品] ✔ 团长已记录"。
- [ ] B 改许愿、发 `xy [手打物品名]`、发 `xy 地板`，两边列表一致。
- [ ] A 鼠标移到 B 那一行，分数两侧出现"−""+"，点击加减分并在团队频道通报；B 那边看不到加减号。
- [ ] A 右键 B 那一行：通报此人许愿、增加 / 扣除分数、标记完成 / 撤销完成、清除此人许愿都能用。
- [ ] A 的工具栏四个通报按钮逐个点一遍（点后 2 秒置灰）；右键底部"未许愿"能通报；状态行"让出"能用；"设置 → 数据"里的按钮逐项试一遍（清空许愿表放最后试）。
- [ ] 底部"未许愿""重复"可点击筛选；列头可点击排序；搜索框能搜角色名和物品名。
- [ ] B 退团再进团，几秒后列表完整。
- [ ] 把团长转给 B，B 点开始许愿，A 自动让位并看到"你已转为团员模式"。
- [ ] 两人都是团长或助理时同时点开始，两边显示的许愿团长一致。
- [ ] 设置页每个分类都点开看一遍；改几个设置后 `/reload`，设置保持。
- [ ] **截图**：主窗口三个标签页各截一张，团长端、团员端都要，发给开发者对照效果图。

## 四、掉落

- [ ] B 在团队频道出一个分数（如 `3`），然后拾取一件紫装：按"自动扣分"规则扣分并通报，两边掉落页都出现这件。
- [ ] B 拾取自己许愿的物品：许愿被标记完成（变淡、删除线）并通报。
- [ ] 后进团的人拿到完整的掉落列表。

## 五、拍卖

- [ ] 有人在团队频道贴一件装备的链接，A 屏幕上出现"待拍 N"按钮；点开选一件即开拍，B 屏幕弹出拍卖窗口，倒计时两边同步。
- [ ] 许愿了这件的人 1 秒后自动出 5 分；出分后计时重置为 10 秒。
- [ ] 两人出同样的分进入 Roll，只有同分的人看到 Roll 按钮；Roll 结算正确。
- [ ] 数秒、直接 Roll、取消拍卖都正常；`/xypm` 能拍第一件。
- [ ] B 点"不要这件"弹窗收成小条；这件再开拍时默认收起；B 自己出分后展开。
- [ ] 结算后掉落页结果列显示赢家和分数（或 Roll 点）。
- [ ] 设置 → 拍卖 → 勾选语音播报，再拍一件，在开拍、倒数、结算等节点能听到语音。

## 六、外围

- [ ] 右键团队成员（团队框体、聊天框里的名字都试）出现"许愿助手"菜单项；只有许愿团长看得到加减分；打开密语、观察等暴雪自带的功能不报"插件被阻止"类错误。
- [ ] 小地图按钮可拖动，重载后位置保持；右键菜单可用。
- [ ] 按键设置里能找到并绑定"显示许愿窗口"。
- [ ] 设置 → 界面 → 切换"暴雪原生"和"扁平暗色"，主窗口和拍卖弹窗都打开时来回切，立即变化、无报错。两种风格各截一张图。

## 七、数据安全

- [ ] A 录入几条许愿后，用任务管理器强制结束游戏进程；重新登录进团后点"开始许愿"，先弹出"来自某某的 N 条许愿记录，是否采用"，采用后列表完整。
- [ ] 正常 `/reload` 后数据完整。
- [ ] "设置 → 数据 → 导出许愿表"，把内容全选复制到记事本；"清空许愿表"后用"导入备份"粘贴回来，许愿表和掉落列表恢复，B 那边也同步恢复。
- [ ] A 中途 `/reload` 一次，之后让 B 再许一次愿，然后强制结束 A 的游戏进程；A 重登后应弹出"用团员的数据恢复吗"，选恢复后数据完整，团队频道出现"请大家核对"的提示。
- [ ] 设置 → 许愿规则 → 退团时清空分别选"弹窗询问"和"直接清空"，退团各试一次。
